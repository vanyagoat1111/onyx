# Этот репозиторий устарел и ничего не деплоит

Здесь лежит витрина ONYX времён позиционирования «разработка сайтов
по подписке». Она больше не соответствует ни модели, ни боевому сайту.

**Боевой сайт onyx-web.ru собирается из `vanyagoat1111/onyx-site`**
(проект Vercel `onyx-site`). Правки вносить туда.

## Не чинить то, что здесь лежит

В этом файле есть всё, что ONYX запрещает на клиентских сайтах:
`cdn.tailwindcss.com`, шрифты с `fonts.googleapis.com`, фотографии
с `images.unsplash.com`, битые пути к картинкам в демо, мёртвые
кнопки в мебельном разделе.

На живом сайте ничего этого нет — проверено 23.08.2026: ноль внешних
доменов в разметке, ни одной битой картинки. Это состояние старого
файла, а не боевая поломка.

Чинить его незачем и опасно: выкладка отсюда откатила бы живой сайт
на версию, которая из России открывается без шрифтов и с пустыми
рамками вместо фотографий.
